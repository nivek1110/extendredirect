===============
Extend Redirect
===============

:Extension key: extendredirect
:Package name: nivek1110/extendredirect
:Version: |release|
:Language: en
:License: GPL-2.0-or-later

Extend Redirect turns TYPO3's Redirects module into a self-maintaining system: it
health-checks redirect targets, disables broken redirects, protects against deleted or
hidden target pages, imports redirects from CSV and keeps an audit log.
